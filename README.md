# Sistema de Coleta e Análise de Dados---Redes-Sociais com....
Python, Spark e MongoDB

📝 Descrição

Pipeline completo para coleta de dados via Twitter API, processamento com Apache Spark, armazenamento em MongoDB e análises exploratórias com Python. Ideal para monitoramento de tendências e análise de sentimentos.
🛠️ Tecnologias

Python
Apache Spark

📂 Estrutura

social-data-pipeline/
 ├── src/
 │   ├── twitter_collector.py
 │   └── spark_processor.py
 ├── data/
 ├── notebooks/
 ├── requirements.txt
 └── README.md

🚀 Como executar

    Configurar credenciais da Twitter API.

    python src/twitter_collector.py

    spark-submit src/spark_processor.py

✅ Resultado

Dataset atualizado de tweets, processado e armazenado para análises avançadas.
